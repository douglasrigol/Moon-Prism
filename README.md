# Moon-Prism-
 Site conceitual de perfume com frasco 3D
 Projeto autoral de direção de arte e experiência digital, inspirado no imaginário de Sailor Moon. Não é um produto oficial. O frasco, as flores e as pedras são modelos 3D que o visitante gira com o mouse, e o site tem cursor em forma de lua, rastro de estrelas e rolagem suave.
